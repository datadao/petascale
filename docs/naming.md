# Naming

Project name: **petascale** (play on "petabyte scale").

Alternatives considered and why not chosen:
- **pet-scale** — collides with existing HA integration `bodypetscale`
- **petascope** — heavily taken by rasdaman's PetaScope geospatial component
- **telltail** — Breeders Coop already uses it
- **meowdao** — excellent Data Dao pun but cat-specific vs. our dog ambitions
- **denwatch** — strong backup; clean, understated, species-agnostic
- **zoozilla** — considered for the ZZ alliteration and mascot energy
- **fauna.ai** / **petcortex** — AI-startup flavor candidates
- **zoolog**, **zoometrics**, **pawmetrics**, **pawlab**, **whiskerlab** —
  also considered

Accepted trade-off: "pet-scale" shares its phonetics with BodyPetScale, but
the scope differs meaningfully. BodyPetScale is a Home Assistant integration
for ideal-weight estimation. petascale is a broader data platform
(preservation, event detection, analytics, future ML/vision). Different
category, different surface area.
